Field Capture Checklist

Condensed, printable version of the Field Capture Methodology — for crews to carry on-site

Condensed field reference — print or save offline. Full explanations are on the Field Capture Methodology page (linked from the Program Overview).

Before you leave the office

  • ☐ Phone, Bad Elf Flex/Flex Mini, Insta360/GoPro — fully charged + spare battery packs
  • ☐ NTRIP login confirmed working (Caltrans CRTN or Point One)
  • ☐ Phone storage cleared
  • ☐ Facility ID + floor list for today's building(s) confirmed

On arrival

  • ☐ Connect Bad Elf to NTRIP → confirm RTK Fix (not Float)
  • ☐ Pair Bad Elf to PIX4Dcatch via Bluetooth → set/verify camera offset
  • ☐ Set 3–5 exterior control points

Pass 1 — Exterior

  • ☐ Walk full perimeter, fixed phone angle, steady pace
  • ☐ Vary distance/height per façade — no robotic straight lines
  • ☐ Capture roofline/eaves from ground, angled up
  • ☐ Close the loop back to start point

Pass 2 — Roof (decision required)

  • ☐ Safe code-compliant access + fall protection? → walk it like an interior floor
  • ☐ No safe access? → do not go up — use EagleView oblique imagery instead
  • ☐ Record capture method used in Survey123 (Roof capture method field)

Pass 3 — Interior (per floor)

  • ☐ One PIX4Dcatch session per floor
  • ☐ Steady pace, fixed angle, ~90% overlap
  • ☐ Pause at stairwells/elevators for control tie-in
  • ☐ Loop + figure-eight pattern for irregular layouts

Pass 4 — 360° Imagery

  • ☐ Station every ~10–15 ft or room center
  • ☐ Consistent height + level
  • ☐ All lights on in dark rooms; avoid direct sun glare
  • ☐ Note position/room per pano

Pass 5 — Asset Tags / Barcodes

  • ☐ Standard iPhone camera, tap-to-focus, fill the frame
  • ☐ Flash/flashlight in low light
  • ☐ Shoot barcodes square-on and flat
  • ☐ Attach each photo + tag ID to the Survey123 Asset Tag Photos section

Before leaving the building

  • ☐ QA spot-check: tape-measure one known distance vs. the live model
  • ☐ File naming confirmed: Facility ID + floor number on every session
  • ☐ Submit/sync Survey123 record

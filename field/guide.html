Complete Field Guide

Capture methodology — exteriors, hardscape, interiors, 360°

This is the full method behind each checklist item. Read once before your first capture day; use the Checklists page in the field afterward.

Tool-to-task map: PIX4Dcatch → building exteriors + park hardscape/infrastructure. Polycam → building interiors. Insta360 R2 → 360° photo/video for all spaces. All positioning ties back to a Bad Elf RTK receiver on WKID 7132.

0. Before You Leave the Office

  • Phone, Bad Elf Flex/Flex Mini, Insta360 R2 — charged, plus spare battery packs
  • NTRIP login confirmed working (Caltrans CRTN or Point One)
  • Phone storage cleared — PIX4Dcatch and Polycam scans are large
  • Facility ID + floor list for today's building(s) confirmed
  • PIX4Dcatch project created and synced to PIX4Dcloud beforehand if possible

1. Exterior Capture — PIX4Dcatch

Used for: building exteriors, park hardscape (courts, paths, plazas), and site infrastructure (fences, signage structures, retaining walls).

  • Pair Bad Elf to PIX4Dcatch via Bluetooth; confirm RTK Fix (not Float) before starting
  • Set 3–5 control points around the perimeter, tied to WKID 7132
  • Walk the full perimeter at a steady pace, fixed phone angle
  • Vary distance/height per façade — avoid robotic straight lines, PIX4Dmatic needs angle variation for reconstruction
  • Capture roofline/eaves from ground level, angled up, if roof access isn't safe
  • Close the loop back to your start point for drift correction
  • For hardscape (courts, paths, plazas): walk a grid or perimeter pattern at consistent height, same overlap rules apply

2. Roof Capture (Decision Point)

  • Safe, code-compliant access + fall protection available? → capture it like an interior floor with PIX4Dcatch
  • No safe access? → do not go up. Use EagleView oblique imagery instead and note the substitution

3. Interior Capture — Polycam

Used for: all building interior floor plan and room-level capture.

  • One Polycam LiDAR Room-mode session per floor
  • Walk continuously — don't stop and shoot; Polycam's LiDAR mode is a continuous scan, keep a steady pace
  • Cover every room, alcove, closet, and restroom — ArcGIS Indoors needs geometry for every unit, not just main rooms
  • Pause briefly at stairwells/elevators to tie floors together
  • Use a loop or figure-eight pattern through irregular layouts to close scan loops and reduce drift
  • Export floor plan as DXF from Polycam Pro when finished — this feeds the ArcGIS Indoors Units/Details import

4. 360° Imagery — Insta360 R2

Used for: the photo tour layer, embedded in facility popups/pages, for every space (interior and exterior).

  • Station every ~10–15 ft, or at the center of each room
  • Keep camera height and level consistent between stations
  • Turn on all lights in dark rooms; avoid direct sun glare outdoors
  • Note the position/room for every pano — this is what lets you link panos to floor plan markers later

5. Asset Tags / Barcodes

  • Standard iPhone camera, tap-to-focus, fill the frame
  • Use flash/flashlight in low light
  • Shoot barcodes square-on and flat, not at an angle
  • Attach each photo + tag ID directly in the Survey123 Asset Tag Photos section

6. Before Leaving the Building

  • QA spot-check: tape-measure one known distance and compare to the live model on-screen
  • Confirm file naming: Facility ID + floor number on every PIX4Dcatch and Polycam session
  • Submit/sync the Survey123 record
  • Upload PIX4Dcatch project to PIX4Dcloud for processing; export Polycam scan (DXF + E57)

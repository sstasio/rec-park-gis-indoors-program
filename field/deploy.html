Deploying This Guide

GitHub Pages, Vercel, or ArcGIS Hub

Straight answer on ArcGIS Hub: Hub can't directly host a multi-page interactive site like this one (it's a page-builder, not a static file host). The right pattern is: host this guide on GitHub Pages or Vercel, then embed it in Hub via an Embed content item (iframe) or link to it from a Hub page/card. That gets you both — a fast, real website AND a presence inside your Hub site.

Option A — GitHub Pages (simplest, free)

  1. In the repo settings → Pages → set source to the branch/folder containing this site (e.g., main / /field)
  2. GitHub gives you a URL like https://sstasio.github.io/rec-park-gis-indoors-program/field/
  3. No build step needed — this is plain HTML/CSS/JS

Option B — Vercel

  1. Import the repo at vercel.com/new
  2. Framework preset: Other (static site)
  3. Deploy — you get a URL like rec-park-gis-indoors-program.vercel.app/field/, with the option to attach a custom domain later

Embedding in ArcGIS Hub

  1. Once deployed (GitHub Pages or Vercel), copy the live URL
  2. In Hub site editor: add an Embed content card, paste the URL — Hub will iframe it in
  3. Alternatively, link individual pages (e.g., the Checklist page) directly from Resource/Initiative cards
Recommendation: GitHub Pages for this internal field-guide site (free, zero maintenance) → embedded into your public/internal Hub site. Save Vercel for anything that later needs serverless functions or a build pipeline — this site doesn't.

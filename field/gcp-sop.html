GCP Placement SOP

Co-registering Polycam (interior) & PIX4Dcatch (exterior) capture

Ground control points (GCPs) are what let an interior Polycam scan and an exterior PIX4Dcatch scan land in the same real-world coordinate space instead of two disconnected point clouds. This SOP defines where to place them, what to place, and how to tie them into our WKID 7132 control network.

Core rule: place GCPs at the physical transition between capture systems — doorways, entry vestibules, loading docks, gate openings — plus intermediate points inside long spans. A target only helps if both systems can actually see it.

1. Why Doorways & Transitions

Polycam (LiDAR/photogrammetry) and PIX4Dcatch (RTK-assisted photogrammetry) each build their own independent mesh with its own local origin unless anchored to shared ground truth. Doorways, vestibules, and gate openings are the literal boundary where one session ends and the other begins — so a target placed there is the only kind guaranteed to be visible to both crews on the same capture day.

2. GCP Target Spec

RequirementWhy
High-contrast coded target (checkerboard or Pix4D-style coded marker)Resolves cleanly in both LiDAR+RGB (Polycam) and pure photogrammetric feature matching (PIX4Dcatch)
Matte finish, no gloss/laminate glareReflective surfaces kill LiDAR return and confuse photogrammetric feature detection
Rigid, flat-mounted (not curled paper)Warped targets shift the apparent center point between the two scans
Minimum 15cm × 15cmNeeds to resolve at typical Polycam interior walking distance and PIX4Dcatch exterior standoff

3. Where to Place GCPs

  • Every building entry/exit doorway used during capture — place a pair: one just inside the threshold, one just outside, not a single target straddling the frame
  • Loading docks and gate openings where hardscape capture meets a building envelope
  • Hallway midpoints or intersections on any interior run longer than ~30–40m — a single doorway GCP won't correct LiDAR drift accumulated deep into a long corridor
  • Stairwell/elevator landings already being used as floor tie-in points in the field guide — treat these as GCP opportunities too, not just Polycam-to-Polycam transitions
Pairs, not singles: one GCP at a doorway fixes translation only. A pair (inside + outside, a few meters apart) lets both systems solve for scale and rotation independently before you trust the merge.

4. Tie Every GCP to Real Coordinates

Don't treat GCPs as purely visual anchors. Log an actual RTK-corrected coordinate for each one using the Bad Elf/Trimble/Eos receiver already in the field kit, tied to WKID 7132 — same rule as exterior control points in the main field guide. That's what turns "both systems can see it" into "both systems land in the same real-world coordinate," which matters once this feeds ArcGIS Indoors floor plans and needs to snap cleanly to Phase 2 exterior hardscape.

  • Confirm RTK Fix (not Float) before logging any GCP coordinate
  • Record GCP ID, coordinate, and the doorway/space it ties together in Survey123 alongside the facility record
  • Use the same control point IDs when setting up both the Polycam scan and the PIX4Dcatch project for that session

5. Field Procedure

  • Set and log all doorway/transition GCPs before starting either scan — retrofitting targets after capture means one system missed them
  • Place the exterior-side target first while RTK Fix is confirmed, then the interior-side target
  • Start the PIX4Dcatch exterior walk from a logged GCP whenever possible, and close the loop back through it
  • Start the Polycam interior scan from the same doorway pair, walking away from the threshold, not toward it
  • Note which GCP pair ties which room to which exterior zone — this mapping is what makes the merge auditable later

6. QA Check

  • Tape-measure one known GCP-to-GCP distance and compare against both the live PIX4Dcatch model and the Polycam scan before leaving site
  • If either system shows more than a few centimeters of disagreement at a GCP, re-shoot that transition before moving on — don't wait until office processing to find out

7. Common Pitfalls

Watch for:
  • Single GCP per doorway instead of a pair — under-constrains scale/rotation
  • Glossy or laminated targets — clean visually but return poorly in LiDAR
  • Long interior runs with no intermediate GCP — accumulated Polycam drift won't get corrected by a doorway target 40m away
  • GCP logged without an RTK Fix — a "visually correct" target with a bad coordinate is worse than no target, since it can silently pull the whole merge off

Realsee & Matterport Ecosystem Evaluation — Advice

Cost structure — the biggest differentiator

Realsee (Galois M2/P4) uses a one-time hardware purchase ($5,499–$7,499) with pay-as-you-go hosting/publishing credits — no mandatory recurring subscription. Matterport (Pro3) requires an ongoing Matterport Cloud subscription per active space, and the E57 point cloud export needed for the ArcGIS Indoors pipeline is gated behind a Professional-tier plan plus an additional one-time purchase per space.

Recommendation

Realsee is the better fit for the core GIS Indoors pipeline given the no-mandatory-subscription model. Matterport is worth a second look specifically if a polished public-facing virtual tour product is a real goal for the Hub site or public engagement.

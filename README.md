# Rec & Park GIS Indoors Program — Reference Site

Static reference site for the ArcGIS Indoors program rollout (RPD, City & County of San Francisco). Includes program justification, capture roadmap, field methodology/checklist, a facility-page presentation prototype, equipment comparison/procurement docs, and Survey123/Dashboard specs.

## Structure

- `index.html` — entry point / hub linking to all pages
- `program-value-justification.html`
- `roadmap.html`
- `field-capture-methodology.html`
- `field-capture-checklist.html`
- `facility-page-prototype.html`
- `capture-method-comparison.html`
- `procurement-brief.html`
- `survey123-form-dashboard-spec.html`
- `files/survey123-xlsform-v2.xlsx`
- `files/dashboard-config-template.json`

## Deploying to Vercel

1. Import this repository in Vercel (vercel.com/new).
2. Framework preset: **Other** (static HTML) — no build command needed.
3. Root directory: repo root.
4. Deploy — Vercel will serve `index.html` and the linked pages as static assets.

Pages can also be embedded individually (via Embed/iframe) or linked as Resources/Initiatives cards in an ArcGIS Hub site once deployed.
